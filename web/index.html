ECK Flasher

Install and update ECK firmware on the HHKB Professional Hybrid Type-S, Classic and Classic Type-S, and the Realforce R3S US TKL.

This browser cannot reach USB devices. Open this page in Chrome or Edge on a desktop computer.

Connect your keyboard

Plug the HHKB in with a USB cable and click Connect. Your browser then asks which device to use: pick the one named HHKB.

Keyboard doesn't start?

Windows: update mode needs the WinUSB driver once. Install it with Zadig for "DFU in FS Mode".

Update

Keyboard firmware keeps pairings and settings. Bluetooth firmware: only when the release notes say it changed.

Back up and restore settings

Keymap, macros, calibration, settings. The file holds macros in plain text: keep it private. Restore only to this keyboard.

To update a Classic running ECK: unplug it, set DIP switch 6 ON, plug it in, set it OFF, then click Connect again.

Switch 6 erases the start of the installed firmware: the keyboard won't type until the install finishes.

Keymap and settings (VIA)

Change the keymap, macros and ECK's settings in VIA with this keyboard definition.

Download via.json JIS: via_jis.json

In usevia.app (Chrome or Edge): Settings, enable Show Design tab; then Design, Load Draft Definition, and choose via.json.

Keyboard doesn't start (Hybrid)

Keyboard doesn't type: take the batteries out, then hold the power switch while plugging in USB (hold 2 s).

Then click Recover keyboard firmware. This needs ECK's boot stub, which Install sets up.

Bluetooth broken (the keyboard works over USB): click Recover Bluetooth firmware, then pick the keyboard.

Connect your keyboard

Plug the Realforce R3S in with a USB cable and click Connect. Your browser then asks which device to use: pick REALFORCE R3S (Topre's firmware) or ECK Realforce R3S.

Keyboard doesn't start?

Only the US TKL (R3SD13) is supported. Windows: update mode needs the WinUSB driver once. Install it with Zadig for "DFU in FS Mode".

Installs ECK through Topre's updater. Takes about 30 s; keep the keyboard plugged in. Topre's settings stay in the keyboard, and Topre's firmware can go back on later (Advanced, below).

Update

Keeps the keymap and settings. While it runs, the Simple Mode light stays magenta.

Back up and restore settings

Keymap, macros, settings and Topre's own data. The file holds macros in plain text: keep it private. Restore only to this keyboard.

Keymap and settings (VIA)

Change the keymap, macros and ECK's settings in VIA with this keyboard definition.

Download via.json

In usevia.app (Chrome or Edge): Settings, enable Show Design tab; then Design, Load Draft Definition, and choose the file.

Keyboard doesn't start (Realforce R3S)

The computer lists "DFU in FS Mode": the keyboard is in ST's update mode. Holding Esc and Caps Lock while plugging the keyboard in takes ECK there (older ECK firmware: no computer answering within 15 s of power-up). Click Recover firmware to install ECK again, or just unplug and plug it in to restart.

The computer lists REALFORCE R3S but it doesn't type: Topre's updater is waiting for firmware. Connect it above and click Install ECK.

Advanced: use a local firmware file

Install and update use the release named below unless you choose a file here (.hfb for an HHKB, .rfb for the R3S); it must match your keyboard. On the R3S, Update with Topre's own .rfb (from Topre's site) puts Topre's firmware back.
