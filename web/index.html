ECK Flasher

Install and update ECK firmware on the HHKB Professional Hybrid Type-S, Classic and Classic Type-S.

This browser cannot reach USB devices. Open this page in Chrome or Edge on a desktop computer.

Connect your keyboard

Plug the HHKB in with a USB cable and click Connect. Your browser then asks which device to use: pick the one named HHKB.

Keyboard doesn't start?

Windows: update mode needs the WinUSB driver once. Install it with Zadig for "DFU in FS Mode".

Update

Keyboard firmware keeps pairings and settings. Bluetooth firmware: only when the release notes say it changed.

Back up and restore settings

Keymap, macros, calibration, settings. The file holds macros in plain text: keep it private. Restore only to this keyboard.

To update a Classic running ECK: unplug it, set DIP switch 6 ON, plug it in, set it OFF, then click Connect again.

Switch 6 erases the start of the installed firmware: the keyboard won't type until the install finishes.

Keymap and settings (VIA)

Change the keymap, macros and ECK's settings in VIA with this keyboard definition.

Download via.json

In usevia.app (Chrome or Edge): Settings, enable Show Design tab; then Design, Load Draft Definition, and choose via.json.

Keyboard doesn't start (Hybrid)

Keyboard doesn't type: take the batteries out, then hold the power switch while plugging in USB (hold 2 s).

Then click Recover keyboard firmware. This needs ECK's boot stub, which Install sets up.

Bluetooth broken (the keyboard works over USB): click Recover Bluetooth firmware, then pick the keyboard.
