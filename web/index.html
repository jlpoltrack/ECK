Install and update ECK firmware on the HHKB Professional Hybrid, Classic and Classic Type-S, from Chrome or Edge. Day-to-day settings live in VIA.

1. First install (from stock)

Installs ECK through PFU's own updater. For the Hybrid this writes both chips; keep it plugged in until it says done (about 3 min).

Keyboard running stock firmware. A Classic already running ECK: power off, set SW6 ON, plug in, set SW6 OFF.

2. Boot stub (Hybrid, once)

Replaces PFU's updater in the first flash bank with ECK's small boot stub, which makes USB updates and recovery possible. The first time it saves your original Bank 1 and data EEPROM: keep both files, going back to stock needs them.

3. Update (Hybrid)

Keyboard firmware (STM32) through ST's USB DFU loader, Bluetooth firmware (nRF52) through the keyboard. Pairings and settings are kept.

Recovery: if the keyboard does not start, hold the power switch while plugging in USB, then update the keyboard firmware. Use Bluetooth recovery mode when the Bluetooth firmware is broken.

Windows: ST's DFU loader needs the WinUSB driver once (Zadig, device "DFU in FS Mode").

4. Backup and restore (Hybrid)

Saves the data EEPROM (keymap, macros, calibration, settings) and the keyboard firmware. Restore writes a saved EEPROM back.
